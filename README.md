# WEBSITE Project

> 🤖 Этот проект был автоматически сгенерирован с помощью AI Constructor Bot

## 📝 Описание

Запрос: "Создай концепцию и структуру лендинга для премиального архитектурного бюро. Стиль — строгий, люксовый минимализм, вдохновленный эстетикой студии Yodezeen.

Основные принципы дизайна:

Сетка (Grid): Строгая геометрическая сетка, но с использованием асимметрии. Много «воздуха» (negative space). Никаких стандартных скругленных кнопок или ярких цветов.

Цветовая палитра: Монохром (глубокий черный, графитовый, теплый серый) с акцентами на натуральные текстуры материалов (бетон, камень, дерево) через фото.

Типографика: Сочетание монументального гротеска (например, Helvetica Neue, Inter или custom sans-serif) с очень тонкими начертаниями. Большие заголовки, минимальный объем текста.

Визуал: Полноэкранные (faded или sharp) изображения, видео-фоны с медленным зумом. Контент важнее декора.

Структура блоков (без «дешевых» маркетинговых триггеров):

Hero Section: Вместо громких лозунгов — только название проекта или бюро и одно захватывающее дух фото/видео. Лаконичное меню (бургер или скрытая навигация).

Philosophy/Manifesto: Короткий текст в 2-3 предложения, выровненный по одной из осей сетки. О подходе к пространству и свету.

The Project (Focus): Большой блок, посвященный одному флагманскому объекту (как Nurai Island). Использование горизонтального скролла или смены полноэкранных кадров. Минимум описания — только технические данные (локация, площадь, год).

Gallery/Archive: Сетка проектов разного размера (masonry grid), где фото являются ссылками. Без рамок, без теней.

Technical Excellence: Блок о деталях (чертежи, макро-фото материалов). Это подчеркивает экспертность без использования «иконок преимуществ».

Contact: Максимально сухой и строгий. Только email, соцсети и адрес. Никаких форм «Перезвоните мне через 30 секунд».

## 🚀 Технологии

- HTML5, CSS3 (Sass/SCSS)
